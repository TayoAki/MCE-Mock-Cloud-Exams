# CertPath learner app

The iOS and Android app for learners, also runnable on web for review. Expo SDK 57, Expo Router, React Native 0.86, TypeScript, Uniwind (Tailwind v4 for React Native) and TanStack Query. The React Compiler is on (SDK 57 template default).

It implements screens S01–S13 from `docs/plan/design/PROTOTYPE_BRIEF.md` against the CertPath API. The server owns grading, deadlines, rewards, streaks and entitlements; the app never computes a grade or XP.

## Run it

```bash
# 1. API (in-memory MongoDB replica set, seeded): from ../api
npm install && npm run dev                 # http://localhost:4000/v1

# 2. App
npm install
npx expo start                             # press i / a / w, or scan the QR code
```

Or run everything from the repo root with `npm run dev` (see the root README, which also covers GitHub Codespaces).

In development the app sends API calls to Metro itself (`/v1` on the dev server), and `metro.config.js` proxies them to `API_PROXY_TARGET` (default `http://127.0.0.1:4000`). Web, simulators, phones on the same network, `--tunnel` and Codespaces therefore need nothing beyond Metro. Production builds use `EXPO_PUBLIC_API_URL` (see `.env.example`).

Expo Go runs everything except push reminders. Those need a development build (`npx expo run:ios` / `npx expo run:android`, or EAS) and an EAS project ID; without one, turning reminders on still saves the preference.

Sign in with the seeded learner `alex@certpath.dev` / `certpath-demo`, or start fresh as a guest. On the first lesson, answering **A, B, B, A, D** reproduces the plan's walkthrough: 3/5 correct and +75 XP.

## Behaviors worth knowing

- **Retry-safe answers.** Each answer gets a `client_submission_id` and is saved on the device before it is sent. A dropped connection shows "Your answer is saved on this device" with Retry; reopening the app resends the identical payload automatically, and the server decides whether it had already committed.
- **Server clocks.** Timed quizzes and mocks count down against the server deadline, offset by the server's clock, and keep running if the app is closed. When time is up the server finalizes the form once.
- **Sealed mocks.** Mock answers show no feedback until submission; results show domain denominators and "Practice score · not a pass prediction".
- **Guests.** A guest gets a real server identity, so grading stays server-side. Registering upgrades that same identity and keeps every attempt and credit. Signing in to a different existing account does not merge guest progress, and the screen says so.
- **Plus.** Plan-gated actions (timed/custom quizzes, full mocks, extra explanations) open the preview screen. The 14-day preview needs an account, starts only on an explicit tap and never renews. Store purchases are not wired up (see the root README).
- **Accessibility.** Controls are at least 44pt, use `role` / `aria-*` props (honored on iOS, Android and web), and decorative icons are hidden from screen readers. Feedback uses words and icons, not just color.

## Checks

```bash
npx tsc --noEmit       # typecheck
npx expo lint          # lint
npx expo-doctor        # SDK dependency check
npx expo export -p ios -p android -p web   # bundle every platform
```

`src/uniwind-types.d.ts` is generated by Metro and committed so a fresh clone typechecks.

One React Compiler gotcha: it reads the property paths a closure uses as memo dependencies during render. A non-null assertion such as `enrollment!.id` inside an event handler therefore crashes while `enrollment` is still loading. Use optional values (`enrollment?.id`) and guard inside the handler instead.
