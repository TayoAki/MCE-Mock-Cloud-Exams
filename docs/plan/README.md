# CertPath v2 — product and design bundle
24 October 2026 · Working title · Design draft

**A Duolingo-style daily path with Pocket Prep-style exam practice.** Short structured lessons drive learning; contextual AI helps after a mistake. Pilot: Databricks Data Engineer Associate. AWS and Microsoft Fabric are planned expansion banks.

## Start here
1. Extract the entire ZIP.
2. Open **START_HERE.html** for the visual index.
3. Open **prototype/index.html** for the offline clickable walkthrough.
4. Read **product/DISCOVERY_PACKET.md** and **product/FACTORY_PRD.md**.
5. Give **database/**, **api/** and **delivery/** to the implementation team.

No installation, login or network is needed for the core walkthrough. Modern browsers can open index.html directly; if local-file restrictions intervene, serve the extracted folder with a local static server. Source links require internet.

## Included
- 13 mock screens, each as editable SVG and 1170×2532 PNG; two concept boards and one overview.
- Offline onboarding, question/feedback/completion and five-question sample mock.
- Six customer journeys, interruption/error journeys and a flow diagram.
- Product scope, design tokens, states, monetization and retention/review rules.
- 38-table PostgreSQL reference schema, draft seed, column dictionary and ERDs.
- OpenAPI 3.1 contract, grading/access rules and AI-helper boundary.
- Prioritized backlog, analytics/evaluation plan, short-form demo scripts and evidence ledger.
- Reference checks with explicit limits.

## Guided walkthrough
From Learn, start a lesson. Choose **A, B, B, A, D** to reproduce 3/5 correct, 75 XP and a fictional streak increase from 3 to 4. Reset demo restores the baseline. Use the screen list to inspect every view.

Practice → Mock starts a 5-question sample. Full-mock scores, review counts, progress metrics and social rosters in preset screens are fictional fixtures.

## Real deliverables and planned work
The HTML walkthrough, visuals, documents, SQL and checks are delivered. No native app, production API, live AI, store billing, authentication, push or social invite service is deployed.

Local prototype answer keys are in JavaScript only for the design demo. Production must grade on the server using the documented private-key boundary. Code-drawn SVG/PNG mocks are design references, not captured browser screenshots. Concept-board copy may vary slightly; the written spec and prototype define exact behavior.

Thirty-three reference checks passed; validation/REPORT.md lists scope and limits. Browser layout, native accessibility and integrations remain untested.

Prices, lesson size, intervals and release gates are hypotheses. The five sample items are original drafts awaiting independent subject-matter review. There is no pass guarantee, validated pass probability, proven virality or measured CertPath revenue/margin.
