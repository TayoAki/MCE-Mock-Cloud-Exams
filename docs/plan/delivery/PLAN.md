|---|---|---|
| M0 Demand/content | Candidate interviews, current blueprint, initial reviewed families | Clear target problem and reviewed usable inventory |
| M1 Core vertical slice | Native exam select → assigned lesson → server grade → complete | Device walkthrough; ownership/idempotency tests |

No delivery dates or team capacity have been validated. Estimate after reviewing content availability, staffing and native integrations.
