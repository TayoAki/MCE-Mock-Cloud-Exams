# Content-first product demos
Use the user’s supplied seven-factor playbook as a production template, not proof of what will go viral. No outlier hunt or viral uplift experiment was completed in this bundle.

The repeatable visual transformation is: **I open the app → know today’s task → answer → understand the mistake → finish a small session.** The product makes choosing and following through on useful practice feel simple.

## Three native screen-recording scripts
| Factor | Daily path demo | Mistake correction demo | Focused mock review |
|---|---|---|---|
| Topic | Certification prep after work | Table history misconception | Choosing the next topic |
| Verbal hook | “Too tired to pick what to study?” | “I thought history meant the files were safe.” | “A score alone doesn’t tell me what to study.” |
| Written hook | “One small lesson tonight” | “This is where I got it wrong” | “Turn a mock into your next lesson” |
| Visual hook | Open S03 with one current node | Select wrong answer in S04 | Show S10 domain breakdown |
| Original value | Actual five-item path and correction | Explain retained log + data with source | Show denominators and focused practice |
| Script angle | Tutorial / real routine | Common mistake / lesson | Transformation / tutorial |
| CTA | “Try a sample lesson” | “Try this concept yourself” | “Take a sample, then review a gap” |
| Format | Screen recording + real creator voice | Screen recording + short reaction | Screen recording / voiceover |
| Editing | Violet, mint, ink; readable captions | Same; show source link | Same; no fabricated success badge |

Example 18-second sequence: 0–3s show a clear question; 3–7s choose an answer; 7–12s show the correction in plain language; 12–16s complete and show the next review; 16–18s invite a sample lesson. Never compress it into “five minutes guarantees a pass.”

For every actual outlier, log topic, verbal/written/visual hook, specific value, angle, CTA, format and editing. Borrow structure and supply our own teaching value. Label all demo scores as illustrative; publish real learning outcomes only with permission and evidence. Do not use a mock score as a certification pass.

The 70/20/10 content mix, 5× follower rule and last-year window come from the user-supplied playbook. They are heuristics to test, not statistically validated distribution rules. Technical cert audiences may behave differently from student audiences.

Keep hooks separate from product claims: virality is an uncertain acquisition result. The real recurring value must be accurate practice and visible correction.
